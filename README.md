# Synthetic Experiments

A playground for exploring synthetic clinical data generation — patient trajectories, event sequences, and other AI-born data.  
This repo collects small, focused experiments before they evolve into something bigger.

> "Every synthetic patient starts as an experiment."

Currently exploring:
- Different synthetic EHR generation methods
- Different LLMs from closed-source, Ollama, HuggingFace platforms
- Evaluation metrics for patient trajectory plausibility
